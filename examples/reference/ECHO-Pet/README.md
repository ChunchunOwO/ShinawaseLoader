# ECHO Classic Pet

参考 Mod：不出现在安装器可选包。自行打包后导入。 See [`../README.md`](../README.md).

把官方「ECHO Pet」小窗换成经典像素桌宠，并带上 VPet 式喂食 / 打工 / 状态面板。源码来自已安装的 `echo.classic-pet` 3.2.0，未改玩法。

Replaces the native ECHO Pet window with the classic pixel pet and VPet-style shop / work / stats panels. This is the installed `echo.classic-pet` 3.2.0 package, copied in as an official example.

## 打包 Pack

```powershell
.\pack-mod.bat .\examples\reference\ECHO-Pet\echomod .\examples\reference\packages\ECHO-Pet.echomod --zip
```
