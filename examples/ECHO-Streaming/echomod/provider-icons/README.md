# Streaming provider icons

These marks identify the corresponding providers in the account page. Brand names and trademarks remain with their respective owners. The assets are stored in the Mod so the UI does not need a third-party icon service at runtime.

The SVG Repo files were recolored for the provider colors; the SoundCloud and TIDAL files were cropped to their pictograms. The QQ Music stroke was made heavier for small sizes. The osu! shape is unchanged, apart from setting its single-color variant to pink in line with the brand guidelines.
